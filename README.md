# Lolzteam Forum Renamer

*Rename forum sections locally*

## How It Works

Double-click a section or subsection name to open an editing field

Enter — save the new name
Escape or click outside the field — cancel editing

Clear the field and press Enter to restore the section’s current name

## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension for your browser
2. Open [lolz-forum-renamer.user.js](https://raw.githubusercontent.com/LolzteamExtensions/Lolzteam-Forum-Renamer/main/lolz-forum-renamer.user.js)
3. Click “Install” in the Tampermonkey window
